D'CELL BUKU KAS 2.0 — UI PREVIEW

Isi:
- index.html
- styles.css
- app.js

PENTING:
Ini adalah prototipe tampilan interaktif dari nol. Belum terhubung ke Firebase Authentication atau Firestore.
Data transaksi yang ditambahkan hanya data sementara di halaman/browser dan tidak dikirim ke server.
Jangan unggah ke Hosting produksi dan jangan menimpa website lama.

Rencana tahap berikutnya:
1. Cocokkan struktur koleksi/dokumen Firestore lama.
2. Gunakan Firebase project d-cell-16fbe dan file firebase-config.js milik pengguna.
3. Implementasikan login Owner/Staff dan pembacaan/penulisan data sesuai struktur lama.
4. Uji di alamat preview terpisah sebelum mengganti website produksi.

Cara melihat:
Ekstrak ZIP, lalu buka index.html di browser untuk melihat prototipe.
